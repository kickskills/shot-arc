Shot Arc PWA 試作パッケージ

公開手順（GitHub Pagesの例）
1. GitHubで新しい公開リポジトリを作成
2. ZIPを解凍し、index.html / manifest.webmanifest / sw.js / iconsフォルダをリポジトリ直下へアップロード
3. Settings > Pages > Deploy from a branch を選択し、main / root を指定
4. 発行されたHTTPS URLをiPhoneのSafariで開く
5. 共有 > ホーム画面に追加 >「Webアプリとして開く」をオン > 追加

このZIP自体に公開URLは含まれません。公開前に名称、利用規約、プライバシーポリシー、問い合わせ先を確定してください。
現在の計算は空気抵抗・回転・リング接触判定を含まない理論モデルです。
